В Python поддерживаются все пять перечисленных принципов.

1. Обобщённые типы через TypeVar, Generic, или Protocol (утиная типизация), параметризированные типы (list[int]) тоже есть. Но это все таки динамическая типизация, и проверяется она только тайпчекерами.
2. Тесно связанные функции можно просто расположить в одном файле и импортировать совместно (либо только "основную", без зависимых.

3. Для объединений модулей в семейства есть пакеты, к которым можно обращаться и настраивать поведение с помощью пакетного init.

4. Динамический полиморфизм. Код может работать через общий интерфейс, не зная заранее конкретный класс объекта.
 Выбор реализации метода происходит во время выполнения через разрешение системы DI.

5. Здесь либо импортировать наборы функций, либо (предпочтительно) уже работать с системой классов.

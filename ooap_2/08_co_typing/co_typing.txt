Для

class Animal:
    pass


class Cat(Animal):
    pass


1. Ковариантность

Будет


class Producer[T]:
    def get(self) -> T:
        ...

И тогда Producer[Animal] к Producer[Cat]

Ковариантны Animal к Cat

То есть класс, типизируемый подтипом, также будет подтипом (то есть вместо любого producer животного можно
подставить любой producer котов)


2. Контрвариантность

Будет
class Consumer[T]
    def hash(self, entity: T) -> int
        ...

И тогда Consumer[Animal] будет контрвариантен Consumer[Cat],
Поскольку вместо любого consumer котов можно подставить любой consumer животных, но не наоборот.

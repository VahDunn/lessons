# Vim Trainer

Практический курс по Vim с заданиями и настоящим редактором прямо в браузере.
Результат проверяется автоматически, прогресс сохраняется между запусками.

## Быстрый старт

Требования: Python 3.10+ и Vim 8+ либо Neovim.

```bash
cd vim_trainer
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -e .
vim-trainer
```

Откроется `http://localhost:8765`. Выбери занятие — задание и Vim появятся в
одном workspace. Дополнительное окно терминала не требуется.

Внутри занятия:

- слева находятся цель, шаги, команды и сворачиваемая подсказка;
- справа работает настоящий Vim;
- `:wqa` сохраняет файлы и запускает проверку;
- кнопка «Отменить» завершает попытку без изменения прогресса.

Dashboard показывает общий прогресс, прогресс по темам и число попыток.
Занятия можно искать и фильтровать по теме или статусу. Доступны светлая и
тёмная темы.

Без аргументов `vim-trainer` запускает browser-интерфейс. Другой порт или запуск
без автоматического открытия браузера:

```bash
python3 -m vim_trainer web --port 9010
python3 -m vim_trainer web --no-open
```

## Курс

51 занятие разбито на 12 тем. Курс последовательно покрывает:

1. навигационную разминку, режимы, сохранение, `hjkl` и базовые перемещения;
2. операторы, text objects, undo/redo, yank/paste и dot repeat;
3. поиск, диапазоны, substitution и `:global`;
4. visual mode, регистры, метки, прыжки и макросы;
5. buffers, windows, argument list и quickfix;
6. продвинутые преобразования и комплексную правку Python-проекта;
7. вложенные и tag text objects, границы поиска `\zs`/`\ze`;
8. рефакторинг через `cgn`, `:move` и последовательные числа;
9. expression register, дописывание макросов и change list;
10. `path`/`:find`, location list, `:ldo` и `:cdo`;
11. `gf`, tags/`Ctrl-]` и цикл проверки через `:make` и quickfix;
12. итоговый многофайловый Python-проект.

Проверяется наблюдаемый результат: содержимое файлов, позиция курсора и, где
нужно, регистры. Последовательность клавиш не диктуется.

## Терминальный режим

CLI остаётся дополнительным режимом:

```text
vim-trainer start               продолжить курс в терминале
vim-trainer start 07            открыть урок по номеру
vim-trainer start 27-named-register открыть урок по id
vim-trainer list                показать карту курса
vim-trainer status              показать общий прогресс
vim-trainer doctor              проверить Python и Vim
vim-trainer reset               сбросить прогресс
```

Тренажёр использует чистую конфигурацию без `vimrc`, плагинов, swap и viminfo.
Своя конфигурация включается флагом `--user-config`, другой редактор — флагом
`--editor nvim` или переменной `VIM_TRAINER_EDITOR`.

## Данные и безопасность

Рабочие файлы создаются в системной временной директории и удаляются после
занятия. Исходные файлы репозитория не открываются и не изменяются.

Прогресс хранится в:

```text
~/.local/share/vim-trainer/progress.json
```

Путь можно заменить переменной `VIM_TRAINER_DATA_DIR`. Запись атомарная и
защищена межпроцессным lock. В `localStorage` хранится только выбранная тема.
Данные активного занятия временно лежат в `sessionStorage` и удаляются после
завершения.

Web-сервер слушает loopback. Изменяющие запросы защищены CSRF-токеном, а доступ
к PTY выдаётся короткоживущим session-токеном. Он позволяет безопасно вернуть
Vim после перезагрузки той же вкладки и перестаёт действовать после занятия.

## Архитектура

```text
vim_trainer/
├── domain/          сущности курса и чистая проверка результата
├── application/     сценарии обучения и порты
├── infrastructure/  PTY/Vim и атомарный JSON-прогресс
├── presentation/    HTTP/WebSocket API, frontend assets и CLI
└── curriculum.py    декларативное содержание курса
```

Зависимости направлены внутрь: presentation и infrastructure знают об
application/domain, но домен не знает ни о браузере, ни о PTY, ни о JSON.

## Разработка

Python:

```bash
python3 -m unittest discover -s tests -v
```

Frontend:

```bash
npm install
npm run check
npm run build
```

`@xterm/xterm` и `@xterm/addon-fit` собираются локально через esbuild. CDN не
используется; готовые `app.js` и `terminal.css` входят в package assets.
